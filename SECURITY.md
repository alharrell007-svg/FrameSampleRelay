# Security reporting

The repository is [alharrell007-svg/FrameSampleRelay](https://github.com/alharrell007-svg/FrameSampleRelay), publicly available. **GitHub private vulnerability reporting is enabled**, verified September 21, 2026.

Use [Report a vulnerability](https://github.com/alharrell007-svg/FrameSampleRelay/security/advisories/new), or **Security → Advisories → Report a vulnerability**, to send a private report. Confirm the form is private before submitting sensitive details. Do not post vulnerabilities, secrets, private videos or exploit instructions in public issues.

If the private reporting button is unavailable, a request to restore it must contain no vulnerability details. Any alternative public contact field requires owner approval; no personal email contact is published. No response-time commitment is made for this prerelease project.

The published prerelease is [0.2.0-rc.4](https://github.com/alharrell007-svg/FrameSampleRelay/releases/tag/v0.2.0-rc.4). Broader supported-version or security-maintenance commitments have not been established. For runtime boundaries and privacy limitations, see [the security review](docs/SECURITY.md).
